# Fernando-Hondoy
¡Bienvenidos a nuestras clases de inglés! En este espacio compartiremos materiales, actividades y ejercicios que nos ayudarán a aprender y mejorar poco a poco nuestro inglés. Trabajaremos vocabulario, lectura, escritura, escucha. La idea es aprender juntos, participar y sentirnos cada vez más seguros al comunicarnos en inglés.
